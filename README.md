# Dummy template resume

An engineering-grade, single-page LaTeX resume template designed for maximum human legibility and algorithmic parsing efficiency.

This repository implements the visual and structural standards established by the **Harvard University Faculty of Arts and Sciences (FAS) Mignone Center for Career Success**, paired with an ATS-optimized parsing architecture, and a harmonious layout.
The document was optimized for ATS friendly standards.

At the core, it follows certain clarity structural guidelines and strong words for sentence structure, like the ones suggested by Harvard's guide to create a great canditate representation: https://careerservices.fas.harvard.edu/resources/create-a-strong-resume/
